# ingfy 设计风格总结

> 依据：`src/styles.css`、`src/lib/palette.ts`、`src/lib/motion.ts`、`src/lib/settings.ts`、README 截图，以及 2026-11-13 的《霓歌：设计定稿 v1》。整理于 2026-11-18。

---

## 1. 一句话概括

**深夜霓虹 + 液态玻璃 + 专辑取色。** 深紫夜色打底，界面控件全是半透明的"玻璃胶囊"，背景和灯光的颜色随当前专辑封面变化；歌词用超粗字重做逐字卡拉 OK；动效参照 Apple，快出慢停，局部带弹性。

关键词：沉浸、发光、通透、跟着音乐呼吸。

---

## 2. 设计原则

1. **内容是主角，控件退后。** 歌词、封面、灯光占据画面；控件收在顶栏和底栏的玻璃胶囊里，鼠标 3 秒不动就滑出画面并隐藏光标。
2. **一切颜色来自专辑。** 背景色块、拾音灯、进度条、开关、歌词默认色都从封面提取，换歌时 1.2 秒平滑过渡。界面没有固定的品牌主色。
3. **玻璃是唯一材质。** 所有浮层（顶栏、播放条、菜单、设置、桌面歌词底）共用同一套玻璃配方，只分"薄玻璃"和"厚玻璃"两档。
4. **比例固定。** 全屏界面按 1440×900 舞台排版，再整体等比缩放到窗口，任何窗口尺寸下比例都不变。
5. **动效有物理感，但不炫技。** 进出场都带一点缩放加模糊，切换用滑块和交叉淡化，不做硬切。尊重 `prefers-reduced-motion`。

## 3. 色彩

### 3.1 基础令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#1A1238` | 默认底色（深紫夜色），也是白色按钮上的文字色 |
| `--c0` ~ `--c5` | `#FF9BB3` `#FF6F91` `#E3579E` `#C34A9F` `#9B47B4` `#6F48C6` | 默认调色板（粉→紫），封面取色失败时用 |
| `--accent` | `#C34A9F` | 默认强调色 |
| `--accent-soft` | `#FF9BB3` | 柔和强调色 |
| 文字 | `#FFF`，次级用白色透明度分层 | 见 3.4 |

`color-scheme: dark`，整个应用默认深色。

### 3.2 专辑取色规则（`palette.ts`）

- 封面缩到 48×48，k-means 取 **6 个主色**，迭代 10 次。
- 每个颜色都调成"发光色"：**亮度拉到 0.55–0.75**，饱和度至少 0.55（乘 1.25）；灰色封面（饱和度 < 0.12）保持低饱和，不会被硬染色。
- 按色相排序后写入 `--c0` ~ `--c5`，一排灯从左到右就能平滑渐变。
- **跟随专辑的底色**（`deepTone`）：挑饱和度最高的颜色，饱和度压到 ≤0.6，**亮度固定 0.11**，得到很深的同色调底，白字始终清楚。
- **色彩鲜艳度**设置映射为 `--vivid = 0.3 + 鲜艳度 × 1.4`，作为 `saturate()` 作用在背景和灯光上。

### 3.3 预设配色（拾音灯和唱片共用，两色插值成 6 色）

| 名称 | A | B |
| --- | --- | --- |
| 霓虹 | `#FF5FA2` | `#7B5CFF` |
| 海洋 | `#3DE8FF` | `#2F5BFF` |
| 落日 | `#FFB547` | `#FF4F7B` |
| 极光 | `#4BF0B5` | `#9B7BFF` |
| 纯白 | `#FFFFFF` | `#C9C4E8` |

### 3.4 文字的透明度层级（深色底）

| 层级 | 颜色 | 例子 |
| --- | --- | --- |
| 主文字 | `#FFF` | 歌名、当前句已唱部分 |
| 次级 | `rgba(255,255,255,0.75)` | 歌手 |
| 三级 | `rgba(255,255,255,0.55)` | 专辑名、来源说明 |
| 未唱 / 占位 | `rgba(255,255,255,0.32)`～`0.45` | 当前句未唱部分、输入框占位 |
| 非当前句 | 按距离计算 `--alpha`，并加 `--blur` | 越远越淡越糊 |

### 3.5 渐变强调

需要"开启"状态的地方（拾音灯开关、菜单开关、小红点）用 **`linear-gradient(135deg, var(--c1), var(--c5))`** 加同色外发光 `0 0 14px`，所以强调色永远是当前专辑的颜色。

### 3.6 两个例外的固定配色

- **墨晕灯效**：宣纸底 `#EFE9DC`，墨色文字 `#1D1A16`（次级用它的 0.6 / 0.45 透明度）。玻璃变成米白磨砂 `rgba(255,253,247,0.55)`，不跟专辑色和任何颜色设置。
- **聊天模式窗口**：仿即时通讯软件的中性配色。浅色：底 `#F5F5F5`、我方气泡 `#95EC69`、对方 `#FFF`；深色：底 `#111`、我方 `#3EB575`、对方 `#2C2C2C`。

## 4. 液态玻璃材质

### 4.1 薄玻璃 `.glass`（顶栏、播放条、小按钮）

```css
background:
  radial-gradient(120% 90% at 18% -10%, rgba(255,255,255,0.22), transparent 55%), /* 左上角弧面高光 */
  linear-gradient(160deg, rgba(255,255,255,0.16), rgba(255,255,255,0.05));
border: 1px solid rgba(255,255,255,0.26);
box-shadow:
  inset 0 1px 0 rgba(255,255,255,0.6),   /* 上沿亮边 */
  inset 0 -1px 0 rgba(255,255,255,0.1),  /* 下沿暗边 */
  inset 0 0 20px rgba(255,255,255,0.06), /* 一圈内发光，做出"厚度" */
  0 24px 60px rgba(8,4,32,0.4);          /* 深紫色投影 */
backdrop-filter: blur(28px) saturate(180%) brightness(1.04);
```

构成要素：**淡白渐变底 + 左上角高光 + 上亮下暗的描边 + 内发光 + 背景模糊提饱和**。

### 4.2 厚玻璃 `.glass--thick`（设置面板、弹出面板等大面积）

- 底色混入专辑色并加深：`color-mix(--c1 22%, rgba(24,16,48,0.62))` → `color-mix(--c5 30%, rgba(12,8,26,0.72))`
- `blur(40px) saturate(170%)`，投影加重到 `0 30px 80px rgba(6,3,24,0.55)`
- 目的：大面板上的文字在任何背景上都看得清。

### 4.3 投影

投影一律用**带紫调的深色**（`rgba(8,4,32,…)`、`rgba(10,4,40,…)`），不用纯黑，让阴影融进夜色。

| 元素 | 字号 / 字重 |
| --- | --- |
| 滚动歌词 | 64px × 用户倍数，**900**，行高 1.18 |
| 桌面歌词 | 38px × 用户倍数 |
| 歌名 | 30px，700 |
| 设置标题 | 26px，900 |

## 6. 形状

- **胶囊为主**：按钮、分段控件、工具栏、开关几乎都是 `border-radius: 999px`（样式表里出现 39 次）。
- **圆形**：图标按钮（44×44）、唱片、圆环灯效、封面占位色块。
- **大圆角卡片**：封面 30px，设置面板 34px，桌面歌词条 36px，提示气泡 20px。
- **小圆角**：输入框、按钮组内元素 10–16px，键帽 6px。
- 灵动岛：收起时高 46、圆角 23（正好半高，胶囊）；展开到 420×172、圆角 36；贴屏幕顶边时上面两个角变直，像刘海垂下来。

## 7. 背景

层次从下到上：

1. **底色** `--base`（默认 `#1A1238`，或跟随专辑的深色调）
2. **流体色块**：3 个超大圆（视口宽度的 44–52%），分别填 `--c1` / `--c5` / `--c3`，透明度 0.4–0.55，**`blur(140px)`**，散落在角落外侧
3. **可选背景**：纯色渐变（135°，c1→c5 混入深底）、自己的图片或视频、专辑封面放大模糊（至少 24px）
4. **暗度层**：带底色色调的半透明黑，透明度由设置控制
5. **歌词压暗**：开着拾音灯时，在歌词列后面加一块径向渐变压暗，保证字可读

所有颜色变化都是 `1.2s ease` 过渡。

## 8. 歌词表现

### 8.1 逐字卡拉 OK

- 每个字是一个 `inline-block`，用 **`background-clip: text`** 的硬边渐变填色：`linear-gradient(90deg, 已唱色 var(--p), 未唱色 var(--p))`，`--p` 随时间连续变化。
- 已唱：`#FFF`（或用户 / 专辑色）；未唱：`rgba(255,255,255,0.32)`。
- 开始唱的字**轻轻上浮 0.11em**（0.35s，`cubic-bezier(0.2,0.9,0.3,1)`），停住不回落；整句结束后通过 `--line-on` 渐变落回原位。
- 颜色变量用 `@property` 注册成 `<color>`，换行时颜色能平滑过渡，不闪。

### 8.2 滚动歌词

- 当前句：最亮、可放大（`--scale`）、带上浮。
- 其他句：按与当前句的距离计算 `--alpha`（变淡）和 `--blur`（变糊），形成景深。
- 悬停非当前句：恢复 0.8 白、去模糊，提示可点击跳转。
- 翻译在原句下一行（当前句 0.72 白），罗马音更淡（0.66）。
- 列表上下边缘用 `mask-image` 渐隐。

## 9. 动效

### 9.1 缓动曲线

| 名称 | 曲线 | 用在 |
| --- | --- | --- |
| `--ease-apple` | `cubic-bezier(0.32, 0.72, 0, 1)` | 默认：快出慢停，无回弹 |
| `--ease-spring` | `cubic-bezier(0.34, 1.32, 0.64, 1)` | 分段滑块位移、拖动排序让位 |
| `--isl-ease` | `cubic-bezier(0.32, 1.28, 0.5, 1)` | 灵动岛展开收起 |
| 唱片换歌 | `cubic-bezier(0.65, 0, 0.35, 1)` | 唱片左右滑出滑入 |
| 退场 | `cubic-bezier(0.4, 0, 1, 1)` | 面板关闭 |

### 9.2 时长

| 时长 | 场景 |
| --- | --- |
| 0.15–0.2s | 悬停、按下反馈 |
| 0.22–0.26s | 退场 |
| 0.32–0.42s | 模式切换进场、灯效切换、分段滑块、灵动岛 |
| 0.5–0.65s | 闲置收起、换歌封面淡入、唱片换歌 |
| 1.2s | 背景和专辑颜色过渡 |

### 9.3 固定套路

- **进场**：从 `scale(1.025)` + `blur(8px)` + 透明 → 落位清晰。
- **退场**：缩到 `scale(0.94–0.975)` + `blur(6px)` + 淡出。
- **按下**：按钮缩到 0.88–0.94，列表行缩到 0.98。
- **分段控件**：白色滑块在选项间滑动（位移用弹簧，宽度用 apple 曲线），按住选中项时滑块轻收到 0.95。
- **拖动排序**（灯效选项）：拖起的选项放大 1.12 变成透亮的玻璃泡，拖得快时沿方向拉长；其他选项用弹簧让位；松手后用 FLIP 弹到新位置。
- **换歌**：封面从 `scale(0.94)` + `blur(12px)` 淡入（0.6s），文字延迟 0.06s 从下方 8px 浮入。
- **闲置**：顶栏上移 140px、底栏下移 160px 并淡出，光标隐藏；鼠标移出窗口 0.7 秒后就收起。
- **桌面歌词工具栏**：悬停时从下方 6px、`scale(0.96)` 浮起。

## 10. 拾音灯

同一份频谱数据，四种渲染：

| 灯效 | 造型 |
| --- | --- |
| 直方图 | 底部分格 LED 柱（14px 亮 / 4px 空），圆角顶，同色外发光 |
| 圆环 | 绕中心一圈辐射的胶囊光条，从专辑色渐变到白，中心有发光圆圈 |
| 声波 | 一排竖直胶囊光条，上下两端发白、中间是专辑色 |
| 墨晕 | 画布绘制，`multiply` 混合在宣纸底上，固定灰黑配色 |

共同点：颜色按位置从调色板取色形成渐变，带 `box-shadow` 外发光，整体透明度 `--light-alpha`（默认 0.85），受鲜艳度 `saturate` 控制。

**3D 模式**：直方图变成镜面地面上的光柱，圆环放平、中心立起封面，声波变成水面光和倒影，墨晕立起一幅山水；歌词也进入场景（墨晕时为竖排书法逐字写出）。

## 13. 不要做的事

- 不用纯黑投影，不用纯黑大面积底（灵动岛除外）。
- 不写死某个品牌色当强调色，强调色永远来自专辑（墨晕和聊天模式除外）。
- 不用直角卡片，不做硬切换。
- 不让灯光盖住歌词：灯开着时歌词后面要压暗，灵动岛里的灯要更暗一圈。
- 不新增别的材质：需要浮层时用薄玻璃或厚玻璃。
